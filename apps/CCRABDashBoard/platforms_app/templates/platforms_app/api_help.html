Getting started

All paths below are relative to this site's origin. Responses use JSON. This reference covers the platforms_app API, including legacy aliases.

  1. For authenticated endpoints, POST your username and password as JSON to {% url 'token_obtain_pair' %}. Use the returned access token in Authorization: Bearer <access>. POST the refresh token to {% url 'token_refresh' %} to obtain a new access token.
  2. GET {% url 'platform-list-api' %} to discover platform short names, platform handles, and sensor observation names and orders.
  3. Request observations using the exact platform_handle and each sensor's obs_standard_name and s_order. URL-encode query values. Use UTC dates ending in Z, or encode the plus sign in positive timezone offsets as %2B.

Public endpoints require no token. The ingestion configuration endpoint also requires membership in private_api_access. An invalid token can cause a 401 even on public DRF endpoints.

Example observation request

Replace the origin, platform handle and observation pair with values from your platform:

curl --get 'https://YOUR_HOST{% url 'platform_data_request' %}' \
  --data-urlencode 'platform_handle=YOUR_PLATFORM_HANDLE' \
  --data-urlencode 'start_date=2026-01-01T00:00:00Z' \
  --data-urlencode 'end_date=2026-01-02T00:00:00Z' \
  --data-urlencode 'observations=YOUR_OBSERVATION_NAME 1'
